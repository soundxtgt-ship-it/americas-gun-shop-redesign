# America's Gun Shop — Website Redesign Mock

Static redesign mock for americasgunshop.us (West Chester, PA).

## Structure
- `index.html` — homepage
- `pages/` — shop, product, services, about, contact, store-ops
- `css/` — design tokens + per-page stylesheets
- `js/` — cart, product data, page modules
- `assets/img/` — imagery and logo

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000
